# 🔥 GrindTime v1.0 - Focus Timer with Face Tracking & Aggressive Motivation

**The ultimate productivity extension that roasts you when you get distracted!**

## 🎉 First Release - What's Included

### ⭐ Core Features

#### ⏱️ Smart Focus Timer
- Customizable Pomodoro-style timer (Work, Short Break, Long Break, Custom)
- Visual progress ring showing time remaining
- Pause and reset functionality
- Background operation - works even when popup is closed

#### 👀 Advanced Face Tracking
- Real-time face detection using canvas-based technology
- Detects when you look away from your work
- Smart throttling prevents false positives
- Visual camera status indicator
- 100% privacy-first - no data leaves your device

#### 🔥 Aggressive Trash Talk System
- **450+ unique roasting messages** - No repetition!
- Anti-repetition system remembers last 50 messages
- Harsh, aggressive motivation with zero pity
- Categories include:
  - Brutal Reality Checks
  - Competitive Fire
  - Savage Financial Reality
  - Direct and Harsh Truth Bombs
- Customizable voice settings (tone, rate, pitch, volume)

#### 📊 Distraction History & Analytics
- Complete distraction tracking with timestamps
- **Timer context** - Shows exactly when in your session you got distracted
  - Example: "⏱️ 3m 15s into 30min session"
- Beautiful stats dashboard showing:
  - Total distractions tracked
  - Face distractions
  - Social media visits
- Filter by type (All, Face Tracking, Social Media)
- Visual timeline of your focus patterns

#### 📱 Social Media Tracking
- Automatically detects 20+ social media platforms:
  - YouTube, Twitter/X, Instagram, Facebook
  - TikTok, Reddit, Discord, LinkedIn
  - Snapchat, Pinterest, Twitch, WhatsApp
  - And more...
- Tracks visit duration
- Shows which platforms distract you most
- Blue styling in history for easy identification

### 🔒 Security Features
- **XSS Protection** - HTML sanitization for all user inputs
- **Content Security Policy** - Strict CSP prevents unauthorized scripts
- **A- Security Rating** - All critical vulnerabilities fixed
- Zero data collection - everything stays local

### 🎨 Beautiful Interface
- Modern dark theme design (#0f172a navy background)
- Orange-to-red gradient aesthetic (#f97316 → #dc2626)
- Smooth animations and transitions
- Professional, clean UI
- Custom logo with timer and eye iconography

### 📈 Daily Streak System
- Track consecutive days of focus sessions
- Visual streak counter with fire emoji
- Syncs across devices via Chrome storage
- Automatic streak maintenance

## 📦 Installation

### Method 1: Load Unpacked (Recommended for now)
1. Download `grindtime-v1.0.zip` from this release
2. Unzip the file to a folder
3. Open Chrome and go to `chrome://extensions/`
4. Enable "Developer mode" (toggle in top-right)
5. Click "Load unpacked"
6. Select the unzipped GrindTime folder
7. Done! 🎉

### Method 2: Drag and Drop
1. Download `grindtime-v1.0.zip`
2. Unzip the file
3. Open Chrome and go to `chrome://extensions/`
4. Enable "Developer mode"
5. Drag the folder into the extensions page
6. Confirm installation

## 🚀 How to Use

1. **Click the extension icon** in your Chrome toolbar
2. **Set your focus time** (default is 25 minutes)
3. **Choose a mode:**
   - 💼 Work (25 min)
   - ☕ Short Break (5 min)
   - 🌴 Long Break (15 min)
   - ⚙️ Custom (your choice)
4. **Click START** to begin your focus session
5. **Stay focused!** The extension tracks your face
6. **Look away?** Get roasted with aggressive motivation! 🔥
7. **View your history** to see distraction patterns
